### Added

- **An invite link now names the friend who sent it and says what the link gives.** The invite screen for a signed-out visitor shows the trip owner's first name or handle. It also shows the role the link admits. The server cuts the name to one word and removes the `@` from a handle. It keeps 24 characters at most. The server does not send an email address, a web address or a phone number. The screen keeps the anonymous wording in those cases. A link with no name or no role also keeps the anonymous wording. The new fields appear after the migration is applied. Until then the screen reads as it does today. (#1036)
