### Added

- **One Add control on phones adds what fits the screen.** The native app shows a raised "+" in the centre of the bottom bar, with a caption under it. The phone web app shows a pill at the bottom right. A slow scroll down shrinks the pill. The label follows the screen: Plan a trip, Add stop, Add place, Add expense, Add decision or Invite people. A long press, the chevron or the keyboard opens a menu with the other actions. The menu scrolls on short screens. A viewer sees only the actions that the role permits. On the full-screen phone map, the control shows a round "+" button above the peek sheet handle. The control hides while a sheet, a dialog or the keyboard is open. Desktop does not change. (#1064)

### Changed

- **On phones and wide native tablets the Add control replaces the timeline Add button and the Chakra button.** When Chakra is on, Ask Chakra is in the Add menu, so tablets show one Chakra button. (#1064)
- **For creators, Creator hub moves to the top of Profile so Add stays in the centre.** The native bottom bar keeps four destinations around the centre slot, and Profile highlights when Creator hub is open. (#1064)

### Fixed

- **A form label now points to the field id when the field sets its own id.** Screen readers read the label name, and a click on the label focuses the field.
- **The Android Back button now closes the open Add menu before it leaves the screen.** Focus returns to the button that opened the menu, and a second Back press walks history as before. (#1064)
