Every value has a name

Existing repo names stay where they already fit: --radius, --radius-sm, --radius-lg, --space-1…10, --icon-stroke, --yf-blur-*, --ring. New families use the --pw- prefix until you pick final names. Each colour shows light on the left, night on the right, and the repo token it replaces.

What the retrofit changed

Measured on every board before and after.
Corner radii24→8distinct values across 28 boards. 869 declarations moved onto the scale. Charts keep 2px inner joins.
Shadows146→32distinct shadow recipes. 374 now read var(--elev-*) or a glow. Outline rings and none stay.
Icon strokes9→1distinct widths on 24px icons. 587 set to 1.9. Charts, routes and the logo keep their own.
Spacing15→0off-ladder gap, padding and margin values. 677 snapped. Hairlines (1px), overlaps and layout alignments kept.
